# רעש יפה — Ra'ash Yafe

Музыкальное приложение для iPhone, доступное через Safari → «На экран Домой».

## Возможности
- Первый альбом «אני פה!» с восемью композициями
- Два независимых варианта (A и B) для каждого трека
- Локальное сохранение MP3, WAV, M4A и обложек
- Прикрепление ссылок Suno, без хранения логинов и паролей
- Музыкальный плеер, клипы, новые альбомы
- Офлайн-режим через Service Worker

Данные песен и файлов хранятся в IndexedDB браузера на устройстве. Экспорт JSON содержит только список и ссылки, не сами медиафайлы — оригинальные файлы храните также отдельно.

## Установка
Откройте опубликованный HTTPS-адрес приложения в Safari на iPhone, нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Безопасность
Не вводите пароль Suno в приложение. Перейти в свою библиотеку можно через официальную страницу Suno.

## Версия 4.1 — автономная студия

- ▶ играет локально сохранённый MP3/WAV/M4A на собственном плеере без перехода на Suno.
- Если есть **только публичная ссылка** Suno формата `https://suno.com/song/<UUID>`, вариант открывается во **встроенном официальном iframe-плеере** на том же экране. Это онлайн-воспроизведение Suno, не копирование файла и не автономное хранение; на эквалайзер звук iframe не попадает. Закрытые песни могут не воспроизводиться.
- 5-полосный эквалайзер (80 / 250 / 1000 / 4000 / 10000 Гц), четыре пресета и ручные настройки. EQ работает с локальными файлами, сохраняется в библиотеке.
- В разделе «● Запись / монтаж» каждой песни можно сохранять **отдельные фрагменты** с микрофона или импортировать MP3/WAV/M4A, затем выбирать «продолжение» или «наложение с заданной секунды».
- «Собрать готовую песню WAV» смешивает исходный локальный трек и новые фрагменты в полноценный WAV (до 8 минут; 32 кГц, 16-bit stereo). WAV сохраняется в вариант A или B, его можно отдельно экспортировать в «Файлы».
- Резервная ZIP-копия включает все исходные фрагменты, готовые миксы и записи. Восстановление старых ZIP-копий версии 2 совместимо.
- Треки №9 «תתקרבי אליי», №10 «אני פה! (ACID RIOT REMIX)» и №11 «בא לי רעש!» добавляются в первый альбом один раз без удаления пользовательских данных.
- Для подключения к Suno не храните пароль в самостоятельном веб-приложении. Браузер не может читать приватные аудиоданные из авторизованной сессии на другом домене.
- **Ограничения iPhone:** запись идёт через микрофон, не захватывает цифровой звук других приложений или вкладок Safari; при блокировке экрана/переключении приложения запись может прерваться. Для наложений используйте наушники. Встроенный Suno iframe остаётся зависим от Suno и интернет-соединения.
- **Сохранность:** IndexedDB — хранилище этого браузера, не постоянный сервер. После пополнения библиотеки сохраняйте полную ZIP-копию во внешние «Файлы»/iCloud Drive. Долгий монтаж может не пройти на малой свободной памяти.

### Путь пользователя

1. Открыть приложение в Safari (добавить на экран «Домой»).
2. В карточке песни нажать **● Запись / монтаж**, выбрать исходную версию (если есть) и запись нового фрагмента с микрофона.
3. Записывать куплеты, соло, бэк-вокал отдельными отрезками; «Продолжение» добавляет после конца композиции, «Наложение» совмещает с ней по времени.
4. Нажать **◉ Собрать готовую песню WAV** и сохранить в версию A/B, при необходимости отдельно в «Файлы».
5. Включить эквалайзер и нажать **Сохранить всё в ZIP**.

## Версия 6.1 — песни Suno прямо в программе

- На главном экране есть кнопка **«＋ Добавить песни из Suno»**. Можно вставить несколько `https://suno.com/song/<UUID>` сразу, при необходимости написать перед каждой ссылкой название через `|`. Связанные записи сохранены в прежних альбомах в `localStorage`.
- Если название совпадает с уже существующей песней, ссылка добавляется к свободному варианту A или B. Если не совпадает, создаётся новая запись с названием, которое можно позднее отредактировать. Повторяющиеся ссылки пропускаются.
- Нажатие **▶** на песне с Suno-ссылкой и без MP3 открывает официальный потоковый iframe-плеер **в самой оболочке** без перехода в новую вкладку. У пользователя остаётся контроль воспроизведения внутри официального плеера; автоматическое воспроизведение следующей песни не поддерживается.
- Короткие ссылки `suno.com/s/<code>` автоматически раскрываются через собственный ограниченный серверный обработчик на Vercel — без логина и пароля, без ручного поиска полного URL. Если Suno недоступен, программа предлагает повторить попытку позже.
- Никакой пароль или cookie Suno не запрашиваются. Публичные/Link-only ссылки могут не воспроизводиться, если Suno закрывает доступ или требует авторизации.
- Потоковое воспроизведение зависит от Suno и интернета, и не создаёт локальный MP3. **Для полного владения файлами и офлайн-прослушивания нужны авторизованные экспорты Suno либо собственные записанные файлы**, которые импортируются отдельно. Встроенный iframe Suno не управляется эквалайзером приложения.
- ZIP-экспорт сохраняет каталог ссылок вместе с другими данными. Музыка, доступная только по ссылке Suno, не включается в архив как аудиофайл.

### Самый простой путь

1. На телефоне открыть Suno и скопировать полный URL песни (из её страницы).
2. В `רעש יפה` нажать **＋ Добавить песни из Suno**, вставить одну или несколько ссылок, нажать **Добавить песни в альбом**.
3. Выбрать песню и нажать **▶** — откроется встроенный официальный плеер.
4. Для независимого офлайн-хранения позднее использовать **＋ Добавить MP3** и **↓ Сохранить всю музыку (ZIP)**.

## Версия 7.0 — одна кнопка «Вставить песню из Suno»

- Пользователь копирует обычную ссылку Suno с iPhone и нажимает единственную кнопку **«Вставить песню из Suno»**. Программа запрашивает доступ к буферу обмена по нажатию и импортирует запись автоматически. Если Safari не разрешил чтение буфера, открывается простое поле для вставки.
- Поддерживаются как обычные `/song/<UUID>`, так и короткие `/s/<code>` ссылки; последний тип автоматически преобразуется в URL композиции посредством строго ограниченного API `https://raash-yafe-links.vercel.app/api/resolve?code=...`. Пароли, cookies и аудиоданные не передаются этому API. Он принимает лишь код ссылки Suno и получает публичный канонический адрес и, когда доступно, название песни.
- При импорте песни получают настоящее название из публичных метаданных Suno (если доступно), а при совпадении названия заполняют свободную версию существующей песни. Дубли ссылок отфильтровываются.
- Сохранённые раньше короткие ссылки также автоматически распознаются при нажатии ▶. После импорта сразу открывается встроенный официальный плеер Suno в приложении, где нужно нажать ▶.
- Это **онлайн-воспроизведение**, не независимая копия MP3. Внешний плеер Suno по-прежнему зависит от доступности сервиса и интернета. Самостоятельное офлайн-воспроизведение возможно только с импортированными локальными аудиофайлами. Сайт и код не обходят ограничения экспорта Suno.

## Версия 9.0 — альбом с отдельными A/B

- В альбоме **11 песен** (первые 8 + ранее утверждённые 9–11). Для каждой отображаются две отдельные кнопки **A** и **B** и статус: **ФАЙЛ** (локальный MP3/WAV/M4A), **SUNO** (ссылка и онлайн-воспроизведение) или **ПУСТО**.
- Если пользователь нажмёт пустую версию, откроется короткая форма для вставки любой ссылки Suno конкретно в неё. Приложение проверяет её через собственный общедоступный Vercel resolver. Если resolver не раскрывает короткую ссылку, она всё равно сохраняется, а пользователь получает честное уведомление о недоступности записи.
- Кнопка **«У меня много ссылок · добавить все сразу»** принимает несколько URL: метаданные песен сопоставляются по подтверждённому названию с существующими 11 композициями, первая свободная версия назначается A, вторая B. Если название определить невозможно, появляется форма выбора — **не создаются чужие/лишние песни по догадке**. Уже сохранённые файлы и ссылки не перезаписываются.
- Добавлена только одна подтверждённая пользователем ссылка из скриншота: **`https://suno.com/s/BR9oVyNqADjGCuVu`**, привязана к свободному варианту A «אני פה!» **при отсутствии этой ссылки в другом месте и при отсутствии собственной записи**. Если URL уже добавлен или A занят, приложение ничего не меняет. Эта ссылка на момент проверки возвращает недоступность в публичном обработчике, поэтому её сохранение **не означает, что музыка воспроизводится**.
- Остальные реальные URL A/B невозможно восстановить из названий песен. Нужен разрешённый доступ к библиотеке Suno, опубликованный профиль/плейлист или предоставленные пользователем публичные ссылки. Нельзя подставлять найденные чужие Suno-композиции по совпадению названия.
- Подключение по ссылке **не создаёт** независимую MP3-копию. Все файлы, локальные записи и старые ZIP-копии остаются совместимы.
